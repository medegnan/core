# Formats de livrables

Les gabarits ci-dessous sont les standards MEDEGNAN pour la production de livrables professionnels. Ils sont conçus pour être lisibles par un dirigeant non expert, portent toujours une décision ou une recommandation claire, et renvoient en annexe tout élément lourd (données brutes, calculs, références juridiques, notes de travail).

Chaque gabarit est publié ici au format Markdown. L'utilisation dans MPOS déclenche leur génération au format Word (.docx) ou PDF via les moteurs `generer-livrable` et `generer-presentation`.
