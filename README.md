# MEDEGNAN CORE

**La méthodologie publique du conseil pour l'Afrique francophone.**

MEDEGNAN CORE est le référentiel méthodologique ouvert du cabinet MEDEGNAN CONSULTING (Cotonou, Bénin). Il décrit les 12 fonctions universelles d'une entreprise, les protocoles d'intervention, les formats de livrables et les typologies utilisés quotidiennement par notre réseau de consultants certifiés.

## Pourquoi ouvrir CORE ?

Parce que la méthode doit précéder l'outil. En Afrique francophone, le conseil souffre de méthodes importées, mal adaptées, et d'un manque de référentiels partagés. CORE est publié librement pour que tout entrepreneur, tout consultant, toute école de commerce africaine puisse s'en emparer.

## Qui peut utiliser CORE ?

Tout le monde, gratuitement, sans conditions commerciales. La licence Apache 2.0 vous autorise à copier, modifier, distribuer, utiliser commercialement — à condition de conserver la mention de paternité.

## Comment est-ce lié à MPOS ?

[MPOS](https://mpos.medegnan.com) est la plateforme SaaS commerciale qui met CORE en œuvre : dossiers clients, moteurs de diagnostic, génération de livrables, suivi de missions, Mobile Money. MPOS n'est pas obligatoire pour utiliser CORE ; CORE n'est pas obligatoire pour utiliser MPOS. Les deux coexistent et se renforcent.
